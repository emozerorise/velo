## Reporting a Vulnerability

If you discover a security vulnerability in Velo, please **do not** open a public issue. Instead, please submit a report via GitHub Private Vulnerability Reporting or contact the maintainers directly.

Please include:
* Description of the vulnerability and potential impact.
* Step-by-step reproduction instructions or proof-of-concept.
* Operating system and architecture where the issue was observed.

We appreciate your responsible disclosure and will respond promptly to security advisories.
