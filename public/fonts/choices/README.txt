Unmodified Google Fonts, pinned to commit 45e3d5269e4a17d823f6d84470bc084dc5ae46f6.
Source: https://github.com/google/fonts/tree/45e3d5269e4a17d823f6d84470bc084dc5ae46f6/ofl
Families: sarabun, notosansthailooped, ibmplexsansthailooped, prompt, kanit,
ibmplexsansthai. Each family has its own bundled SIL Open Font License.
Static faces include upright Regular (400) and SemiBold (600); Noto Sans
Thai Looped is the original variable font, renamed only for URL simplicity.
No network connection is needed at runtime. The previous default Noto Sans
Thai asset remains unchanged in the parent directory.
